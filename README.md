# WordPress Batch Import Plugin

A high-performance WordPress plugin for importing large datasets using AJAX batch processing.

## Features

- AJAX Batch Processing
- Resume After Interruption
- Queue-Based Import System
- Retry Failed Items
- Rate Limiting
- Progress Bar
- WordPress Admin Interface
- Optimized for Large Imports
- Scalable Architecture

## Built With

- PHP
- WordPress
- JavaScript (AJAX)
- HTML
- CSS
